# Localização

As traduções deste aplicativo seguem o [guia de localização do OCL Design
System](https://openconceptlab.github.io/ocl-design-system/guides/localization.html).

Antes de criar ou alterar uma string, consulte o guia para as regras de composição
de texto e o glossário canônico. Preserve as chaves, os parâmetros de interpolação
(`{{name}}`) e as tags de componentes (`<0/>`) do catálogo em inglês.
